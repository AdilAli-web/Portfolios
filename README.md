# Adil Ali — Java Backend Developer Portfolio

A personalized developer portfolio built with **Next.js, React, and custom responsive CSS**, based on the visual direction of the CodeBucks Next.js portfolio starter.

It highlights my Java/Spring Boot projects, backend fundamentals, database work, Docker practice, and current learning around Kafka and microservices.

## Run locally

Requirements: Node.js LTS and npm.

```bash
git clone https://github.com/AdilAli-web/Portfolios.git
cd Portfolios
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Featured work

- **BookMyShow — Ticket Booking:** Spring Boot REST backend with movie/show discovery, seat booking and cancellation, transaction handling, pessimistic locking, DTO validation, JPQL and global exception handling.
- **Task Management API:** Java 21 and Spring Boot CRUD API with JPA/Hibernate, MySQL, Spring Security configuration and Docker support for the app and database.
- **Java Banking System:** Console application for practicing Java OOP and collections.
- **StudyMate:** Study-focused application project.

The project links on the page open the corresponding GitHub repositories.

## Skills highlighted

- **Java:** OOP, Collections, Generics, Exceptions, Streams, Multithreading, JDBC and DSA.
- **Spring / backend:** Spring Boot, Spring MVC, REST APIs, Spring Data JPA, Hibernate, validation, DTOs, transactions and exception handling.
- **Data:** MySQL, SQL, entity relationships, JPQL and JOIN FETCH.
- **Tools:** Docker, Docker Compose, named volumes, Git, GitHub, Maven and Postman.
- **Learning now:** Kafka topics/partitions/consumer groups, ZooKeeper vs KRaft, microservices and API Gateway concepts.

Kafka and microservices are presented as learning areas rather than production experience.

## Deploy

This is a standard Next.js app and can be deployed to Vercel:

1. Import `AdilAli-web/Portfolios` into Vercel.
2. Keep the framework preset as **Next.js**.
3. Deploy with the default build settings.
