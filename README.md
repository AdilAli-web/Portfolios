# Adil Ali — Java Backend Developer

A typography-first, responsive single-page portfolio built with **Next.js 15, TypeScript, Tailwind CSS, Framer Motion, and Lenis**. The visual direction takes inspiration from minimal editorial portfolios while keeping the content specific to my Java backend work.

## Run locally

Requirements: Node.js LTS and npm.

```bash
git clone https://github.com/AdilAli-web/Portfolios.git
cd Portfolios
npm install
npm run dev
```

Open http://localhost:3000.

## Features

- Editorial, typography-led layout with generous whitespace and a neutral palette
- Animated name preloader and scroll-reveal sections
- Custom cursor on pointer devices; hidden on touch
- Smooth scrolling powered by Lenis
- Light mode by default with a dark mode toggle
- Responsive navigation and full-screen mobile menu
- Semantic sections and SEO metadata
- Project links to GitHub; no unverified live demo URLs are advertised

## Current stack and learning

Java, Spring Boot, REST APIs, Spring Data JPA / Hibernate, MySQL, Docker, Docker Compose, Git, Maven, and Postman. Kafka and microservices are represented as current learning topics, not production experience.

## Deploy to Vercel

Import `AdilAli-web/Portfolios` into Vercel and use the default Next.js build settings. This repository has not been deployed from this change, so a live URL is not yet available.

## Inspiration

Inspired by the typography-first feel of [mijobello.com](https://mijobello.com/). This is an independent implementation and does not copy the original site's assets or source code.
